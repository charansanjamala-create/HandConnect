# HandConnect — Interactive Air-Drawing & Musical Interface

HandConnect is a browser-based creative coding web application that turns index-finger hand gestures and cursor movements into neon air-drawing canvases and responsive musical soundscapes.

## Key Features
- **Index-Finger Air Drawing:** Real-time gesture-driven neon brush strokes directly in the browser without external hardware.
- **Cursor-Triggered Audio:** Interactive Web Audio sound synthesis triggered by motion and gesture coordinates.
- **Zero-Install Web App:** Runs natively in modern browsers using HTML5 Canvas, JavaScript, and computer-vision tracking.

## Tech Stack
- **Frontend:** HTML5 Canvas, CSS3, Vanilla JavaScript
- **Audio & Vision:** Web Audio API, Browser MediaStream / Hand Tracking
